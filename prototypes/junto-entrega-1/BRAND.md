# Junto — Entrega 1 (marca + onboarding + grupo orbital + contactos)

Prototipo de diseño (Vite + React + framer-motion). Sirve para validar marca y UX antes de portarlo
a las pantallas Expo de `frontend/app/` (welcome, onboarding/*, group, invite).

## Marca
- Nombre: **Junto** · Claim: **Juntos, se llega mejor.**
- Símbolo: una órbita y dos puntos (tú en el centro, los tuyos en movimiento).
- Tipografía: Cabinet Grotesk (títulos) + Satoshi (texto), Fontshare.
- Paleta: Noche #0D0F14 · Papel #F3F0E8 · Brote #CFF26B (acción) · Latido #FF6A4D · Cielo #67C6FF · Ámbar #FFC452.

## Niveles de contacto
- Brote (lima): en tu plan, todo incluido.
- Cielo (azul): ya usa Junto con otro plan; puede pasar a tu plan.
- Ámbar: sin app, entra por enlace web con funciones limitadas y aviso de descarga.

Descubrimiento de contactos: hash del número en el dispositivo, comparación en servidor, sin guardar números de no usuarios (RGPD).

## Ejecutar
    npm install && npm run dev
